# pine and spruce v0.8.3

This release corrects the Enter key on a bookmark in pine. Enter now plays the
book or the podcast episode of the bookmark. spruce has no change.

## Installation

```sh
go install github.com/Thelost77/pine@v0.8.3
go install github.com/Thelost77/pine/cmd/spruce@v0.8.3
```

As an alternative, download an archive from the release page. See "Binaries".

## Binaries

The release has one archive for each program and each system. The name of an
archive is `<program>_v0.8.3_<system>_<architecture>`:

| System | Architecture | File type |
|--------|--------------|-----------|
| `linux` | `amd64`, `arm64` | `.tar.gz` |
| `darwin` (macOS) | `amd64`, `arm64` | `.tar.gz` |
| `windows` | `amd64` | `.zip` |

Each archive contains the program, the `LICENSE` file of pine, and a `licenses`
directory. That directory has the license texts of Go and of the modules that
the program links.

- A binary needs libmpv. See "Requirements".
- On Windows, put `libmpv-2.dll` in the directory of the program. The archive
  does not contain it.
- The binaries are not signed.
- A GitHub Actions workflow builds the binaries on Linux with `CGO_ENABLED=0`.
  No binary of this release has run on a test machine.

## pine

### Reliability and Correctness

Bookmarks:

* **Enter on a bookmark moved the item that played, not the item of the
  bookmark.** While book A played, Enter on a bookmark of book B moved book A
  to the time of the bookmark. pine now stops book A, and then starts book B
  at the time of the bookmark.
* **Enter on a podcast bookmark did not use the episode of the bookmark.** An
  Audiobookshelf bookmark has no episode. While an item played, pine moved
  that item to the time of the bookmark. While no item played, pine asked the
  server to play the podcast with no episode. pine now finds the episode from
  the title of the bookmark, and starts that episode at the time of the
  bookmark.

### Changes of Behavior

* Enter on a bookmark seeks the player only if the book or the episode of the
  bookmark plays. If not, Enter stops the current playback, and then starts
  the book or the episode of the bookmark at the time of the bookmark.
* pine finds the episode of a podcast bookmark from the title of the bookmark.
  pine puts the episode title and ` — ` before the title of a podcast bookmark
  that it makes. Each release of pine does this. If you edit the title of a
  podcast bookmark, keep that part.
* Some podcast bookmarks have no episode title at the start of their title:
  the user changed the title, or a different program made the bookmark. For
  such a bookmark, Enter seeks the player if the podcast of the bookmark
  plays. If not, pine shows the error `cannot find the episode of this
  bookmark`, and the playback does not change.
* If two episodes of a podcast have the same title, pine uses the first of
  them in its episode list.

## spruce

spruce has no change in this release. The changed packages, `internal/app` and
`internal/screens/detail`, are part of pine only.

## Development

* Each correction has a test that failed before the correction. The tests use
  a fake Audiobookshelf server and the mock player of the app tests.
* No real Audiobookshelf server ran for these corrections, and pine did not
  run in a terminal. The tests send messages to the model and read its state.
* The statement that an Audiobookshelf bookmark has no episode is from the
  bookmark type of pine, in `internal/abs/types.go`. The source of
  Audiobookshelf was not read for this release.
* The answer of Audiobookshelf to a play request for a podcast with no episode
  is not known. pine does not send that request for a bookmark now.
* The notes of v0.8.2 named two tests that failed at times in CI on Windows:
  `TestE2E_LoginFailure` and `TestE2E_CacheSurvivesRestart`. The two tests now
  wait up to 15 seconds for the commands that can be slow. Each other command
  of a test has a wait of 200 ms, as before. CI ran two times on that change,
  and the two runs passed. Two runs do not show that the fault is gone.

## Requirements

- Go 1.26.4 or newer, for an installation from source
- libmpv from [mpv](https://mpv.io/) 0.34 or later
- pine: an [Audiobookshelf](https://www.audiobookshelf.org/) server
- spruce: a [Jellyfin](https://jellyfin.org/) account with a music library
