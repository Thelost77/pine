# pine and spruce v0.12.1

This release changes subliminal mode in spruce.
A track that you start stops the mix and plays, with no error.
pine has no change.

## Installation

```sh
go install github.com/Thelost77/pine@v0.12.1
go install github.com/Thelost77/pine/cmd/spruce@v0.12.1
```

As an alternative, download an archive from the release page.
See "Binaries".

## Binaries

The release has one archive for each program and each system.
The name of an archive is `<program>_v0.12.1_<system>_<architecture>`:

| System | Architecture | File type |
|--------|--------------|-----------|
| `linux` | `amd64`, `arm64` | `.tar.gz` |
| `darwin` (macOS) | `amd64`, `arm64` | `.tar.gz` |
| `windows` | `amd64` | `.zip` |

Each archive contains the program, the `LICENSE` file of pine, and a `licenses` directory.
That directory has the license texts of Go and of the modules that the program links.

- A binary needs libmpv. See "Requirements".
- On Windows, put `libmpv-2.dll` in the directory of the program.
  The archive does not contain it.
- The binaries are not signed.
- A GitHub Actions workflow builds the binaries on Linux with `CGO_ENABLED=0`.
  No binary of this release has run on a test machine.

## pine

pine has no change in this release.
No shared package changed.

## spruce

### Changes of Behavior

* **A track that you start stops subliminal mode.**
  Before, the error `stop subliminal mode before starting another track` showed, and the track did not play.
* **A track from the library, a playlist, or the command palette replaces the queue.**
  The mix stops, the queue has only the new track, and the track plays.
* **A queue entry that you start keeps the queue.**
  This is for Enter on the queue screen and for a queue entry in the command palette.
  The mix stops, and the entry plays.
* **The sleep timer continues after such a start.**
  The command palette entry `Stop Subliminal Mode` still stops the timer, because the playback stops.
* **The `b` key does not start or stop subliminal mode.**
  Use the command palette entries `Start Subliminal Mode` and `Stop Subliminal Mode`.
  `Stop Subliminal Mode` keeps the queue.
* **On the queue screen, `b` shows the previous page.**
  The library screen and the playlist screen already use `b` for this.

### Fixes

* **A start of the track that plays sends the MPRIS signal `Seeked` with the position 0.**
  The media controls of the desktop then show the new position.
  Before, a start from the library sent no `Seeked` signal for the same track if that track was not the first queue entry.
  When the first queue entry played, a start of a different track sent a `Seeked` signal.
* **While subliminal mode is active, the command palette entry `Repeat Current Track` shows an error.**
  The error is `stop subliminal mode before using this queue action`, as for the other queue actions.
  Before, the entry did nothing.

## Development

* The change is in one commit, [`e84280d`](https://github.com/Thelost77/pine/commit/e84280d3c4c4a90c54b56766b4ee66da18afe247) (fix(spruce): stop subliminal mode on a track start).
* A code review of the change found one defect in the new code: the missing `Seeked` signal while the mix prepared.
  It also found two older defects in the same code: the wrong `Seeked` signals after a start from the library, and the silent `Repeat Current Track` entry.
  Each fix has a test that failed before the fix.
* The new test file `internal/spruce/app/mpris_linux_test.go` starts the MPRIS server of spruce on a private D-Bus bus and checks the `Seeked` signals.
  It skips if `dbus-daemon` is absent.
  With `PINE_REQUIRE_DBUS=1` it fails instead.
* On Linux, `gofmt`, `go vet`, `golangci-lint` 2.14.0, and the tests with `PINE_REQUIRE_LIBMPV=1` and `PINE_REQUIRE_DBUS=1` passed.
  The spruce tests also passed with `-race`.
* The [CI workflow for `e84280d`](https://github.com/Thelost77/pine/actions/runs/45385683452) passed on Ubuntu, macOS, and Windows.
* spruce did not run against a Jellyfin server with this change.
* The dependencies have no change.

## Requirements

- Go 1.26.4 or newer, for an installation from source
- libmpv from [mpv](https://mpv.io/) 0.34 or later
- pine: an [Audiobookshelf](https://www.audiobookshelf.org/) server
- spruce: a [Jellyfin](https://jellyfin.org/) account with a music library
