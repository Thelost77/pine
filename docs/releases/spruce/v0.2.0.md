# spruce v0.2.0

Spruce 0.2.0 adds local repeat caching and concurrent subliminal playback.

## Highlights

- Cache repeated tracks in a private 2 GiB session cache
- Replay cached tracks locally instead of transferring media again
- Play up to eight queued tracks together in subliminal mode
- Loop every subliminal track independently at 20% volume per track
- Pause and change volume for the complete subliminal mix
- Start or stop subliminal mode with `b` or the command palette

## Reliability

- Cancel repeat downloads when repeat is disabled
- Preserve repeat targets across queue reorder and removal
- Isolate mpv groups so stale commands cannot affect newer sessions
- Detect unexpected subliminal mpv process exits
- Reject stale normal mpv launch and position events
- Remove partial cache files after cancellation or download failure
- Keep cached media and cache directories owner-only

## Desktop integration

- Expose a subliminal mix as one synthetic MPRIS item
- Disable seek and track navigation for simultaneous playback
- Report subliminal playback at its fixed 1.0x rate

## Installation

```sh
go install github.com/Thelost77/spruce@v0.2.0
```

## Requirements

- Go 1.26.4 or newer
- `mpv` available in `PATH`
- A Jellyfin account with a music library
- A Unix-like operating system

Linux is the primary platform. Windows is not supported in this release.
