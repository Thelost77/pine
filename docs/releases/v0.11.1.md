# pine and spruce v0.11.1

This release adds the flags `-v` and `--version` to pine. spruce had only
`--version`, and it now also accepts `-v`. The release has no other change.

## Installation

```sh
go install github.com/Thelost77/pine@v0.11.1
go install github.com/Thelost77/pine/cmd/spruce@v0.11.1
```

As an alternative, download an archive from the release page. See "Binaries".

## Binaries

The release has one archive for each program and each system. The name of an
archive is `<program>_v0.11.1_<system>_<architecture>`:

| System | Architecture | File type |
|--------|--------------|-----------|
| `linux` | `amd64`, `arm64` | `.tar.gz` |
| `darwin` (macOS) | `amd64`, `arm64` | `.tar.gz` |
| `windows` | `amd64` | `.zip` |

Each archive contains the program, the `LICENSE` file of pine, and a `licenses`
directory. That directory has the license texts of Go and of the modules that
the program links.

- A binary needs libmpv. See "Requirements".
- On Windows, put `libmpv-2.dll` in the directory of the program. The archive
  does not contain it.
- The binaries are not signed.
- A GitHub Actions workflow builds the binaries on Linux with `CGO_ENABLED=0`.
  No binary of this release has run on a test machine.

## pine

### New Features

* **pine shows its version.** Use `pine --version` or `pine -v`. pine writes
  its name and its version, for example `pine v0.11.1`, and stops. A local
  build that has no version shows `dev`.
* The version is the same value that pine sends to Audiobookshelf as the
  client version of a play session.

### Changes of Behavior

* pine now reads the flags before it opens the log, the config file, and the
  database. `pine --version` and `pine --help` create no files.

## spruce

### New Features

* **spruce accepts `-v`.** It is a second name for `--version`. The usage
  line is now `Usage: spruce [-v | --version]`.

## Development

* The change is in one commit, `168fa8c` (feat: print the version with -v and
  --version).
* On Linux, `gofmt`, `go vet`, `golangci-lint` 2.14.0, and the tests with
  `PINE_REQUIRE_LIBMPV=1` and `PINE_REQUIRE_DBUS=1` passed.
* Both binaries ran with `-v`, `--version`, `-version`, and `--help` and with
  an empty config directory. The directory stayed empty. `pine --clear-cache`
  still cleared the cache.
* No test covers the flags. The `Release` workflow checks the output of
  `spruce --version` for the tag. It does not check pine.
* The dependencies have no change.

## Requirements

- Go 1.26.4 or newer, for an installation from source
- libmpv from [mpv](https://mpv.io/) 0.34 or later
- pine: an [Audiobookshelf](https://www.audiobookshelf.org/) server
- spruce: a [Jellyfin](https://jellyfin.org/) account with a music library
