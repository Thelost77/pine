# pine and spruce v0.6.0

This release puts pine and spruce in one repository and one Go module. The two
programs now share the player, MPRIS, logger, and UI code. One tag releases the
two programs.

## Installation

```sh
go install github.com/Thelost77/pine@v0.6.0
go install github.com/Thelost77/pine/cmd/spruce@v0.6.0
```

The spruce install path is new. The old path, `github.com/Thelost77/spruce`,
stays at v0.2.0.

## pine

### What's New

* **Captions** — pine shows VTT captions from Audiobookshelf sidecar files.
  Press `c` during playback.
* **Finished marks** — the series and detail screens mark finished books.

### Reliability and Correctness

* Pine waits while mpv opens a long stream.
* Pine fully evicts the progress caches on cleanup and restart.
* An MPRIS Play or Pause request now sets that state. Before, each request
  toggled playback.
* An MPRIS SetPosition request now seeks to the absolute position in the
  current track.
* Pine now passes the current volume to mpv at launch.
* The error banner removes terminal escape sequences and stays on one line.

### Security and Storage

* The Audiobookshelf token is not in the mpv process arguments.
* The log file has mode `0600`. If a second pine process is in operation, it
  writes to `pine-<pid>.log`.

## spruce

* An MPRIS SetPosition request now seeks in the current track. Before, spruce
  ignored each request.
* There are no other functional changes.
* The version number changes from v0.2.0 to v0.6.0, because spruce now uses the
  tag of the shared module.

## Requirements

- Go 1.26.4 or newer
- [mpv](https://mpv.io/) installed and available in `PATH`
- pine: an [Audiobookshelf](https://www.audiobookshelf.org/) server
- spruce: a [Jellyfin](https://jellyfin.org/) account with a music library
